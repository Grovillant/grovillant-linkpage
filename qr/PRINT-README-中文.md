# Grovillant 设计 / 印刷交付说明 v1.0.0

这包是正式图稿，不是截图。设计师不需要安装 Python。
**可立即排版、打样；批量开印前必须完成下面的线上和实物验收。没有完成的项不能当作通过。**
主品牌今天继续用根域名，未新增需要上线才可用的 /q/brand。

完整命名为 grovillant-qr-用途-v1.0.0-PRINT.svg，PNG 为同名加 -600dpi.png。
同一用途的 SVG 与 PNG 内容相同，只选一种放版面。优先 SVG；软件不支持才用 PNG。
每个文件的准确像素、URL、版本及 SHA-256 在 QR-MANIFEST.json。SHA256SUMS.txt 供复核整包。
不要用项目根目录的老 PNG / 屏幕截图替换这些文件。

## 怎样放到版面上

- 黑码、实白底，保持正方形。现成白边已留六格，不准裁掉。至少四格的依据：DENSO WAVE https://www.qrcode.com/en/howto/code.html/index.html 。
- 不拉伸、不有损压缩、不模糊、不裁切、不反白、不加透明底、底纹、渐变或反光效果。不放折线、封口、接缝、弧面边缘。
- 本版码内没有叠 logo。品牌 logo 放白边外，不能碰白边或三个角的定位方块；不要自行把 logo 压到码上。H 容错不是随意遮挡的许可。
- 上表是保守的打样起点，不是保证可扫的行业绝对下限。小物料先按 25–30 mm、手机距 15–30 cm 测；展会 80 mm 先测 30–80 cm；广告 50 mm 先测 20–50 cm。要更远就放大并实测。
- 尺寸指完整正方形（含白边）。PNG 有 600dpi 标记，但排版时仍须手动设定毫米尺寸；不要按其像素对应的原始物理大小直接放大。缩小须保持有效分辨率至少 300dpi，禁止放大位图造成像素不足。

## 开印前必须逐项验收（设计方 + 品牌负责人）

1. 对照文件名和 manifest 核对用途、版本、URL；扫描应先得到表中的域名入口。
2. 用最终排版导出的印刷文件，按最终毫米尺寸、实际纸张、油墨和覆膜打样，至少两部不同手机。
3. 明亮、室内普通光、偏暗各扫；正面及斜角扫；确认白边完整、无糊边、折痕和反光遮挡。每种物料都测。
4. 手机在真实网络打开落地页，不能 404、证书报错或循环跳转。五个渠道最终网址应保留 utm_source=qr 和对应 medium/campaign。
5. 点 WhatsApp 确认打开正确的品牌会话，点 Email 确认收件地址正确；不必发送消息。电脑脚本只能查按钮，不能代替这一步。
6. 品牌负责人登记纸张、尺寸、版号、日期、手机和通过/不通过，签字后再批量印。测试结果记录放内部运营目录，不混入交付包或 Git。

## 印后与维护

首批每种物料从前、中、后段各抽一张；每次加印、换纸、覆膜、改尺寸都重验。
上线改跳转后当日、次日各检查一次；每月由品牌负责人巡检全部六个入口及两个联系按钮。
出错先恢复上一版目标或改到可用品牌页，保留渠道 UTM，不能删除旧短路径。
只按渠道看合计访问，不建立个人扫码档案。不要把客户资料、手机号、员工信息、token 写进二维码或统计参数。

## 重生成（只给维护人员）

在代码 worktree 内安装 requirements-qr.txt 后运行：

    python3 generate_qr.py --version 1.0.1
    python3 scripts/validate_qr.py --pack print-pack/v1.0.1

同版本输出目录存在就拒绝写入；新版本需更新说明、登记变更并重新验收。
